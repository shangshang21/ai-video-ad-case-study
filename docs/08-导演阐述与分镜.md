# 08 · NOCTELLE《Wear the Night.》导演阐述与分镜（草案 v1）

> ⚠️ 分镜已经被 [10 · 分镜 v2](10-分镜v2-30秒里的取舍.md) 取代；本篇保留 v1 的原貌，用来对照改了什么、为什么改。

> 30 秒，16:9（抖音竖屏版另做）。下面是“为什么这么拍”和“怎么拍”，正式出片前还会按实际素材调整。

## 一、一句话

**入夜的那一刻，是她涂上口红的那一刻。**

“Wear the Night”字面上是“把夜色穿在身上”。这条片子里，夜不只是背景，而是她嘴唇上那抹酒红。整条片子讲的是一个**仪式**：夜色降临 → 她拿起口红 → 颜色落到嘴唇上 → 她抬眼回看镜头，夜从此归她所有。

## 二、情绪弧线

| | 开头 | 结尾 |
|---|---|---|
| 光 | 黑暗，只有远处的城市光斑 | 金色的轮廓光把她和口红勾出来 |
| 节奏 | 慢，雨声，呼吸 | 快，越切越快，冲到定版 |
| 视线 | 她被看（我们透过窗、隔着暗看她） | 她回看（直视镜头，掌控感） |
| 颜色 | 酒红只在远处的光斑里 | 酒红在她嘴唇上、在液体里、在丝绸上 |

## 三、视觉规矩

1. **三色色板**：酒红、黑、暖金，加上自然的肤色。**不出现蓝色**（S4 月光就是因为冷银色被淘汰的）。
2. **光**：明暗对照（chiaroscuro）。一盏暖色侧光当主光，金色轮廓光勾边，其余都沉进阴影里。暗是我们的朋友：它显得贵，也能藏住 AI 的瑕疵。
3. **质感优先**：缎面膏体、黑漆、抛光金、黑缎手套、丝绒、雨滴、液体。每个镜头都至少给观众一种“摸得到”的质感。
4. **人物锁脸**：三视图加左眼下的小痣。人物镜头按“侧光 + 局部”来拍，不拍正脸大头照。
5. **字很少，很小，很贵**：用跟 P3 一样的高对比衬线体（Didone），白色加酒红两色，全片最多三次文字。汽水广告那种大字砸屏（AURA 的 HEAT、PSHHHT!）适合活力品类，**高端口红要克制**，调性要跟着品类走，连字体也一样。

## 四、镜头语言

| 手法 | 用在哪 | 为什么 |
|---|---|---|
| **慢推**（dolly in） | 开场的窗、她的眼睛 | 一点点靠近，造成亲密感和期待 |
| **焦点转移**（rack focus） | 从玻璃上的雨滴转到城市光斑 | 把观众的视线从“这里”带到“那里” |
| **光扫**（light sweep） | 一道光从左到右扫过黑漆管 | 产品第一次亮相，不是直接给，而是被光“揭开” |
| **微距加升格慢动作** | 膏体旋出、液体、丝绸 | 质感要靠慢和近来展示 |
| **顿帧**（hit-stop） | 拔开盖子那一声 “CLICK.” | 在节奏上给一个重拍，相当于 AURA 的 PSHHHT! |
| **匹配剪辑**（match cut） | 膏体斜面 → 嘴唇弧线；涟漪的圆 → 光斑的圆 → 瞳孔的圆 | 这就是咱们的“转场”，靠形状和颜色的押韵把镜头串起来，比特效转场高级 |
| **环绕**（orbit） | 丝绸漩涡里的口红 | 高潮段的动势 |
| **速度坡度**（speed ramp） | 第三幕开始 | 从慢动作突然加速，情绪“起飞” |
| **低机位** | 产品英雄镜头、定版 | 让一支口红显得有分量 |
| **平视、侧光** | 所有人物镜头 | 平视显得亲近，侧光显得有故事 |

**声音的记忆点**：**“咔哒”**，口红盖子的磁吸声，首尾各响一次。开场拔盖“咔”，定版合盖“哒”。跟「汐」的“啵 / 叮”是同一个思路。

**配乐**：暗调、性感的极简电子，深沉的低音脉冲，约 96 BPM（一拍 0.625 秒）。第一、二幕每 **两拍**切一刀（1.25 秒，跟 AURA 的平均镜头长度几乎一样），第三幕每 **一拍**切一刀，最后两秒每 **半拍**切一刀，冲到定版。定版前静音一拍，然后“咔哒”。

## 六、怎么用 MiniMax H3 出片
- 分成 **3 条，每条 12–15 秒**，按三幕来分。每条里用 `[Shot N] At MM:SS.mmm` 写 8–9 个镜头，按官方的六段式提示词写（Ref2VA）。
- 参考图：`<Subject 1>` = 模特（M1、M2、M3），`<Subject 2>` = 口红（P1、P2），场景图（S1、S2、S3-A、S3-B、S5、P3）当作 `<Picture N>` 首帧或构图锚。每条最多带 9 张，前 5 张免费。
- 每条生成的素材比实际用的长，剪辑时从里面挑最好的那 1 秒左右。
- 文字全部后期用 ffmpeg 加，**不让 H3 写字**，最稳。
