# 07 · 工具说明

都是边做边写的小脚本，放在 [tools/](../tools/)。依赖：Python 3.9+，以及 `pip install imageio-ffmpeg mlx-whisper numpy scipy soundfile librosa`。脚本默认 ffmpeg 在 `tools/bin/ffmpeg`，可以从 imageio-ffmpeg 里软链接过来。

| 脚本 | 用途 | 用法 |
|---|---|---|
| `shotsheet.py` | **拆片**：找出视频里的硬切点，每个镜头取一帧，拼成带编号、起始时间和时长的分镜联系表，并打印镜头数和平均时长 | `python shotsheet.py 视频.mp4 输出目录 [阈值=0.3]` |
| `board.py` | **审图拼板**：几张图缩到同宽，左上角标上名字，按网格拼成一张（总指挥看图的顺序可能跟我们发的不一样，所以**每张图都必须带名字**） | `python board.py 输出.jpg 列数 图1=标签1 图2=标签2 ...` |
| `sunburst.py` | 调用 OpenAI 图片 API（默认 `gpt-image-2.5-sunburst`），可以带参考图，会打印 token 用量和费用估算。key 从 `~/.config/openai/key` 读取 | `python sunburst.py 提示词.txt 输出.png --ref 参考.png --quality high --size 1536x1024` |
| `gen_images.sh` | 通过 Codex CLI 按顺序批量出图，**一次只跑一个任务**。提示词从 stdin 传入，避开 `-i` 吞参数的坑 | `gen_images.sh 输出目录 "名字\|参考图名或-" ...` |
| `review.swift` | 没有 ffmpeg 时的审片工具：用 AVFoundation 抽帧做联系表，再画一条每 0.25 秒的音量时间轴，用来对节拍 | `swiftc -O review.swift -o review && ./review 视频 输出目录 [单独导出的秒数...]` |
| `letterbox.swift` | **遮幅**：裁掉画面底部一条（乱码字幕常在那里），画面重新居中，上下补黑边 | `swiftc -O letterbox.swift -o letterbox && ./letterbox 输入 输出 110` |
| `minimax_video.py` | 调用 MiniMax H3 视频 API（v2）：提交 → 轮询 → 下载 → 记账，支持首帧、首尾帧、参考图。key 从 `~/.config/minimax/` 读取 | `python minimax_video.py 提示词.txt 输出.mp4 --first 首帧.png [--last 尾帧.png] --duration 6` |
| `run_all.py` | 按 manifest 三路并行出片，已经出过的跳过 | `python run_all.py [名字过滤...]` |
| `motion.py` | 每条片子每 0.25 秒的**动作量**（相邻帧差）和**音量**，用来挑剪辑点、找“死时间” | `python motion.py 片名1 片名2 ...` |
| `cut_v1.py` … `cut_v4.py` | 每一版粗剪的剪辑脚本，用 EDL 表驱动：入出点、转场、原声增益、J-cut、推近、定格出字。v4 加了按帧精确的时间线、吸附拍点、配乐和音效 | `python cut_v4.py` |
| `temp_score.py` | 临时配乐：按画面时间点用 numpy 合成的极简暗调电子乐（加法合成、毛毡钢琴、心跳低音、滴答、卷积混响） | `python temp_score.py 输出.wav [时间点.json]` |
| `minimax_music.py` | 调用 MiniMax 音乐 API（纯音乐）。**2026-08-20 起对新用户关闭**，留着做记录 | — |

## 审片的常用手法
- **联系表**：每 0.9 秒或每个镜头抽一帧，一眼看清节奏和穿帮
- **音量时间轴**：判断台词、音效是不是落在计划的那一秒
- **场景切换分数**：`select='gte(scene,0)'`，最高值不到 0.03 说明没有硬切
- **互相关**：两段音频的相关系数接近 1，说明是同一段素材
- **Whisper 转写**：检查台词说对没有（转写时要防它在没人声的地方瞎编）
- **脸部并排裁切**：检查是不是同一个人
