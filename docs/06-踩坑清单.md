## 视频模型（Gemini 会员视频）

| # | 现象 | 原因 | 对策 |
|---|---|---|---|
| V1 | 写了“不要字幕”，还是出了乱码字幕 | 有台词时，模型很爱自作主张加字幕 | **不写台词**；非要台词就后期遮幅裁掉（[letterbox.swift](../tools/letterbox.swift)） |
| V2 | 中文对白带口音（像广东腔），Whisper 转写也听错了字 | Gemini 的中文发音不稳 | 写明 *standard Mandarin*；中文对白交给国产模型，或者后期配音 |
| V3 | 写了 smile 和 tears，结果咧嘴大笑，一点泪都没有 | 模型抓住第一个具体动作就演 | 按发生顺序写：先“眼眶红、咽一下”，再“嘴角慢慢抬起”；写明 *not a big grin* |
| V4 | 两个人“对视后同时躲开”拍不出来 | 两个人卡同一时间点的互动太难 | 一个镜头只拍一个人的动作，需要同步的戏拆成两个镜头 |
| V5 | 两条片子里的“同一个女生”其实是两张脸 | 不给参考图时，模型只给“同一类型”的脸 | 连续剧情用人物三视图锁脸 |
| V6 | 借纱帘遮挡，偷偷换了背景和人的位置 | 遮挡物被模型当成了转场 | 提示词里写“同一扇窗、同一个位置，从头到尾不变” |
| V7 | 两条不同的片子，7 秒以后的声音一模一样 | 聊天端要了“旋律”，可能就塞一段现成的音乐 | 每条只要音效、不要音乐；音乐后期统一配 |
| V8 | 3 到 4 秒总会突然推一下镜头 | Gemini 的习惯动作 | 需要稳定镜头时写清楚 *steady, no sudden push-in* |

## 生图模型（GPT Image 2.5 / Sunburst）

| # | 现象 | 原因 | 对策 |
|---|---|---|---|
| I1 | 三个视角拼成一张图的“产品卡”喂给视频模型 | 宫格版式会被视频模型带进画面（MiniMax 官方文档里写的） | 锚定图做成**三张独立的照片** |
| I2 | 用 Sunburst 改图，背景总被换成参考图里的丝绒幕布 | images/edits 接口会把参考图的背景一起学走 | 参考图只给产品本身，不带场景 |
| I3 | 手跟背后的人对不上，像从别处伸进来的 | 前景手和背景脸分开画，没有处理好空间关系 | 把手臂和身体画出来；或者拆成两个镜头 |
| I4 | 想省额度，把丑图交出去 | 心疼额度 | 生图很便宜（Sunburst 一张约 $0.054），丑就重画，或者出几个方向来挑 |
| I5 | 液体颜色总往“三文鱼粉”跑 | 模型对“peach”的理解偏饱和 | 写明 *paler, translucent, soft blush, not salmon* |
| I6 | API 报 “Project does not have access to model” | 项目的模型白名单里没有生图模型 | 后台 Project → Limits → Model usage 里加上 |
| I7 | 不确定 Codex 用的是 2.5 还是 2.0 | 内置工具不能选模型，图片元数据也不写版本号 | 需要 Sunburst 时走 API |

## 流程与审美

| # | 教训 |
|---|---|
| P1 | **调性跟着品类走**：汽水是活力和夏天，口红、香水才走高端。高端风的汽水瓶画出来像一瓶化妆水 |
| P2 | **色板只用三种颜色**，几十个镜头才像同一个世界 |
| P3 | **差距在剪辑**：平均 1 秒一个镜头，短镜头能藏住 AI 的缺陷 |
| P4 | **广告要有因果链**：动作 → 后果 → 变形 → 揭示，每个镜头都是上一个镜头动作的结果 |
| P5 | **先拍最难的那个镜头**：它能成，整条就稳了；不成，换方案也只损失一条额度 |
| P6 | **提示词要准、要有顺序，不是要长**。10 秒塞 5 个节拍，前 3 个能演出来，后面的就丢了 |
| P7 | **技术瑕疵别盖过气质判断**：手势不对能修，第一眼的质感才最要紧 |
| P8 | 起品牌名之前先搜一遍，确认不跟真实品牌撞名；模特必须是虚构的人 |

## 工具与环境（macOS）

| # | 现象 | 对策 |
|---|---|---|
| T1 | Mac 上没有 ffmpeg，也没有 Homebrew | `pip install imageio-ffmpeg`，它自带一个 ffmpeg 二进制；在那之前用 AVFoundation 写 Swift 小工具顶着 |
| T2 | `codex exec -i 图片 "提示词"`，提示词被当成第二张图片吞掉，退出码却是 0 | 提示词改从 stdin 传进去 |
| T3 | zsh 里 `$F:text` 被当成 `$F` 加上 `:t` 修饰符 | 变量一律写成 `${F}`，复杂的滤镜拼接改用 Python |
| T4 | git 走了一个已经失效的本地代理（127.0.0.1:7897） | 单条命令加 `-c http.proxy=`，并清掉代理环境变量 |
| T5 | ffmpeg 输入里有无限长的 `color` 源，报 “Cannot write more than one file” | 加上 `-frames:v 1` |
| T6 | Whisper 遇到没人说话的音频，会编一句“请点赞订阅” | 先看 `no_speech_prob`，或者加 VAD |
| T7 | 一次并发好几个 Codex 生图任务，把整个 5 小时额度窗口烧光了 | 生图一次只跑一个任务，按顺序排队（[gen_images.sh](../tools/gen_images.sh)） |
| T8 | MiniMax 音乐接口返回 HTTP 410 / 2153 “no longer available to new users” | 2026-08-20 起付费音乐接口不再对新用户开放（不扣钱）；开源的 MiniMax-Music3 只能在 CUDA 上跑。改用 Gemini App 里的 Lyria 3.5 生成纯音乐 |
| T9 | 剪辑脚本按“出点 − 入点”算的时间线，和实际渲染出来的差了 0.15 秒，卡点全偏 | trim 只留时间戳落在 [入点, 出点) 里的帧，fps 滤镜在结尾还会再丢一帧。按 `ceil(出点×24) − ceil(入点×24) − 1` 帧来算，和实际帧数一帧不差 |
| T10 | `alimiter=limit=0.75` 设了上限，真峰值却还是 +0.3 dBFS，响度反而变大 | alimiter 默认开着 `level`（自动把输出拉回 0 dBFS），要加 `level=0`；再给 AAC 编码的过冲留 2 dB 余量 |
