# 16 · 剪辑 v2：去掉“拼凑感”

> 总指挥看完粗剪 v1：“有些过渡还是太生硬，拼凑感还是太严重。”
> 导演的实话：我**看不了视频**，只能看一帧一帧的截图，节奏顺不顺、一刀切得舒不舒服，没法凭感觉判断，只能靠分析数据。所以这一版先用数据把能量化的问题修掉，凭感觉的部分还要靠总指挥的眼睛。

成片：[粗剪_全片_v2.mp4](../assets/05-video/粗剪_全片_v2.mp4)（34.8 秒，压缩版 12.6MB）

## 拼凑感从哪来（用 [tools/motion.py](../tools/motion.py) 量出来的）
1. **声音断层，这是最大的元凶**：每条 H3 片子自带的声音响度差了将近 50 dB（最安静 -66，最响 -12）。每切一刀，声音就“咯噔”一下，耳朵比眼睛更早察觉到“这是拼起来的”
2. **切点落在动作中间**：比如睁眼那条，转头的动作在 2.75–3.75 秒，v1 在 3.3 秒、也就是动作最猛的时候切走，下一镜却是静止的侧脸
3. **颜色不统一**：每条片子的亮度、色温都不一样
4. **全是硬切**，没有呼吸

## v2 做了什么（[tools/cut_v2.py](../tools/cut_v2.py)）
| 问题 | 改法 |
|---|---|
| 声音断层 | 每段原声单独淡入淡出（80/120 毫秒）、按响度做增益；底下铺一条**连续的雨声**（第一镜的雨声循环）和很轻的房间底噪，切镜头时耳朵感觉不到断 |
| 开灯 | **J-cut**：开灯的“咔”提前 0.45 秒进来，画面还在侧影上就先听到了 |
| 切点 | 按动作曲线重定入出点：睁眼等转头**做完**再走；推门在她迈步之前切；丝绒成裙的结尾帧和后拉揭示的开头帧是同一张图，两条接起来像一镜到底 |
| 转场 | 只在有理由的地方用软转场：膏体 → 睁眼用**黑场**（0.25 秒），睁眼 → 侧影用**叠化**（0.3 秒），丝绒天空 → 丝绒涌入叠化（0.45 秒），快闪 → 定版用黑场；其余都是硬切 |
| 颜色 | 所有镜头统一过一遍：微提对比、降饱和、暗部偏暖、暗角、胶片颗粒 |

**量化结果**：每 0.5 秒取一次响度，相邻两点跳变超过 12 dB 的次数，从 v1 的 **13 次降到 1 次**；整片响度范围从 48 dB 收窄到 23 dB。

## 技术上踩的坑
- **用一帧长的 xfade 来模拟硬切会弄乱时间码**，后面的画面直接丢失（第一次只渲染出 4 秒）。改成硬切的镜头先 concat 成“块”，块与块之间才用 xfade
- **每段裁切都会舍掉零点几帧**，累积起来，一个块会比计算的短 0.1 秒以上，xfade 就“够不着”，画面在 12 秒处中断。改成按**实际渲染出的帧数**来排时间线
- 截图时要加 `-pix_fmt yuvj420p`，不然 mjpeg 编码器会报错

## 还没解决的
- 配乐：音乐才是把镜头“粘”起来的最强胶水，要等到有配乐以后按节拍重新卡点
- 凭感觉的节奏：需要总指挥指出具体哪几秒还生硬
- **加了胶片颗粒以后码率暴涨**：crf 19 输出了 75MB，手机收不了（上限 30MB），推到 GitHub 也会触发大文件警告。改成 `-crf 23 -maxrate 3M` 以后是 12.6MB，肉眼看不出差别。仓库里的版本已经换成压缩版（第一次提交的 75MB 版本还留在 git 历史里）
