# 06 · Codex 新增费用明细

核对日期：2026-10-22。范围：Codex 接手原始粗剪后的新增工作，覆盖 27 秒 v2、30 秒融合 v4 以及这次仓库归档。

**按当天 MiniMax 国内官方按量刊例价折算，本支线新增 API 用量约 ¥9.51，其中 H3 视频生成 ¥9.50。这个数字是用量估算，尚未核实为账户逐任务的实际人民币扣款。**

## 1. 两条新增 H3 素材：¥9.50

| 用途 | 任务 ID | 模型 / 分辨率 | 接口返回的输出秒数 | 官方刊例价 | 折算金额 |
|---|---|---|---:|---:|---:|
| 补口红使用近景 | 455143580877205 | MiniMax-H3 / 768P | 4 秒 | ¥0.50 / 秒 | ¥2.00 |
| 配乐载体视频，仅取声音 | 455143907721618 | MiniMax-H3 / 768P | 15 秒 | ¥0.50 / 秒 | ¥7.50 |
| **H3 合计** | **2 个成功任务** | | **19 秒** | | **¥9.50** |

本次已实时查阅 [MiniMax 国内官方定价概览](https://platform.minimax.cn/docs/pricing/overview)：MiniMax-H3 的 768P 输出按秒计费，每秒 ¥0.50；每次输入 5 张以内的图片免费。使用近景输入 2 张参考图，配乐载体没有输入参考图或视频，因此这里没有另加图片或视频输入费用。

计算采用 [生成任务摘要](../manifests/generation.json) 中接口返回的 `usage.output_seconds`，不是按媒体容器的实测时长收费；也没有把 H3 返回的 token 数套用语言模型的 token 单价。

## 2. 语音识别检查：粗估约 ¥0.01

为检查配乐源中是否存在可转写歌词或对白，成功调用一次 `asr-1.0`，音频时长约 15.075 秒。官方语音识别刊例价为 ¥2.50 / 小时，按音频时长直接折算：

```text
15.075 ÷ 3600 × 2.50 = ¥0.01046875
¥9.50 + ¥0.01046875 = ¥9.51046875，显示为约 ¥9.51
```

这里没有核实 ASR 的最小计费单位、取整规则及本账户实际积分换算，故该项为粗估。控制台的语音用量数量字段与音频实测时长也不直接等同。

## 3. 哪些工作没有重复产生素材生成费

- 两条 H3 素材先用于 v2，随后复用到 v4；没有按两个剪辑版本各收一遍生成费用。
- 融合 Claude v3 / v3.2、制作音效和片尾、混音、转码、重渲染、生成预览和整理仓库均使用已有素材与本地工具，没有为这些操作新建 H3 任务。
- 没有为本支线购买剪辑软件或曲库授权。FFmpeg、Python 和 uv 用于本机处理。
- 旧音乐接口返回 HTTP 410 / 业务码 2153，没有得到成功音乐作品，不按一条成功音乐生成列入估算；实际失败请求是否产生账务项目未逐项核实。

上述范围不包含 Codex / ChatGPT 订阅或推理额度分摊、本机电费、人工时间，也不包含 Claude 主线此前的生图和出视频成本。

## 4. 实际账户扣费核对到哪里

本轮已读取用户已登录的 MiniMax 控制台。对应凭据属于订阅 Key / 积分调用，账户存在充值积分；用量页同时出现其他视频任务，页面按小时和模型汇总用量，没有提供这两个任务 ID 对应的逐项人民币扣款。

因此没有用整个账户的余额变化推定本项目实扣，也没有把充值金额当作本项目已经花掉的金额。当前结论是：

| 口径 | 状态 |
|---|---|
| 成功 H3 任务、分辨率、输出秒数 | 已有接口结果支持 |
| 官方单价与参考图免费规则 | 2026-10-22 实时查阅官方文档 |
| H3 刊例价折算 | **¥9.50** |
| 加一次 ASR 后的刊例价粗估 | **约 ¥9.51** |
| 两个任务在积分账户中的精确扣除与人民币分摊 | **未核实，不能写成已实扣 ¥9.51** |

机器可读的计算依据见 [costs.json](../manifests/costs.json)。本文仅记录本支线费用；Claude 主线历史费用继续以其原有记录为准，不把历史估算相加后称为整片实付总额。
