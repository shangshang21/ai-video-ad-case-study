# 02 · 配乐、音效与片尾

这部分记录声音与片尾的实际制作路线。声音素材由 H3 生成，随后使用 FFmpeg 和 Python 编辑、合成与混音；没有使用歌曲库，也没有真人作曲或配音。

## 1. 最初想要怎样的声音

根据黑金夜景、红唇与织物的视觉方向，提出克制的低音脉冲、少量钢琴和逐渐展开的弦乐。让开盖、织物释放和最后合盖各有位置，音乐与画面形成起伏。

这里需要区分创作要求与实际确认：

- 提示词要求约 80 BPM、D 小调、器乐、无歌词和对白。
- 本轮没有测量确认生成结果的 BPM、调性，也没有做自动节拍追踪。
- 镜头是按叙事阶段与动作排的，音乐随后重新组织；没有声称已经完成逐拍卡点。

## 2. 音乐接口失败后怎样继续

先尝试 MiniMax 音乐接口 `POST /v1/music_generation`，请求纯器乐，服务返回 HTTP 410、业务码 2153，说明该音乐 API 不向新用户继续开放。

随后改用 `POST /v2/video_generation`：让 **MiniMax-H3 生成一条 15 秒带器乐配乐的视频**。视觉只要求深酒红织物、黑背景和缓慢运动，重点要求连续、清楚的器乐声音。

任务成功后下载 MP4，用 FFmpeg 提取音轨。这个载体视频**没有进入广告画面**，只作为声音来源。完整请求文字见 [score_prompt.txt](../prompts/score_prompt.txt)，原始结果见 [score_generated.mp4](../assets/source/score_generated.mp4)。

任务请求为 15 秒，提取的音频实际约 15.075 秒。没有因为请求成功就认定音乐风格已经达到广告终审标准。

生成过程中还遇到一次网络 `fetch failed`；重新查询同一个任务后取回结果，没有重复创建一条生成任务。

## 3. 怎样把 15 秒声音组织成 30 秒

v2 先完成 27 秒声音。融合版 v4 按新时间线重新排布，主要做法如下：

| 声音层 | v4 的实际处理 |
|---|---|
| 开场音乐 | 取生成音轨前 6.3 秒，降低增益并淡入淡出 |
| 开场延续 | 再取源音轨 1.0–4.5 秒，从成片 5.8 秒处低音量叠入，衔接到产品段落 |
| 主体音乐 | 从成片 9.25 秒开始放入完整生成音轨，头尾做包络 |
| 尾部延续 | 取末尾 2 秒，在 24.25、25.35、26.45、27.55 秒处逐次降低音量叠加 |
| 低音氛围 | 本地正弦波、少量倍频与滤波噪声，作为很轻的连续底层 |
| 音乐避让 | 在开盖和合盖附近给音乐加短暂的音量下凹，让动作声更清楚 |

末尾延续是延迟、重复与衰减叠加，没有把它称作真实空间的混响采样。具体数组、增益和包络保存在 [render_v4.py](../tools/render_v4.py) 的 `add_soundtrack()`。

## 4. 两版音效有什么不同

**v2** 的开合盖点击、织物掠过和氛围层由本地代码合成。点击声把短促滤波噪声与衰减正弦波叠加；织物纹理由带通噪声乘以缓慢起落的包络生成。

**v4** 采用 Claude 视频中与画面对应的原生开合盖声：

- 开盖：取 Claude v3.2 的 9.25–11.50 秒，放到成片 7.25 秒处，保留同段声音。
- 合盖：取 Claude v3 的 30.50–34.9167 秒，音频用 `atempo=1.17777778` 跟随画面变速，放在成片 23.25 秒处。
- 织物与低音氛围仍使用本地合成的层。

没有在每一次切镜处都加转场音效。声音分为 [混音试听 MP3](../assets/audio/v4_mix.mp3) 与工程包内的音乐、音效分层，便于继续调整。

## 5. 混音怎样验证

内部混音使用 48 kHz、立体声、24-bit PCM WAV。先测量，再使用 FFmpeg `loudnorm` 进行第二遍处理，最后编码 AAC 放进 MP4。

| 版本 | 最终 MP4 综合响度 | 最终 MP4 真峰值 |
|---|---|---|
| v2 | -17.00 LUFS | 约 -3.57 dBTP |
| v4 | -16.99 LUFS | 约 -1.41 dBTP |

v4 的处理目标真峰值为 -1.5 dBTP，AAC 编码后的实测值略有差别，清单保留实际测量读数。检查完整解码与峰值后，没有发现数字削波。

另外调用语音识别检查配乐源，得到空文本。这只说明**未识别出可转写对白或歌词**，不能证明完全不存在类似人声的音色，更不能代替真人试听。

## 6. 片尾如何做

v2 使用左侧深色底和透明文字图层，右侧保留合盖画面。品牌使用 `NOCTELLE`，广告语沿用 `Wear the Night.`，没有新增色号、持妆或功效文案。

v4 换成 Claude 的近景后，产品已经足够突出，因此保留完整夜景与大理石台面：

1. 从 Claude v3 的 34.0 秒提取还没有烧录文字的左侧背景，作为干净背景片。
2. 左侧背景边缘用透明度渐变衔接；在合盖镜头接近结尾、旧文案开始出现前覆盖左侧区域。
3. 右侧保留实际合盖动作；最后停在产品已经合上的一帧。
4. 品牌与广告语用独立透明图层淡入，停留至 30 秒结束。

这是视频图层合成，没有重新生成产品画面。主要字体为 Windows 自带 Times New Roman、Times New Roman Italic 与 Arial；字距、字号和位置见 `make_titles()`。

## 7. 还需要怎样的验收

本轮完成了声音数据检查、图层和关键画面的核查，**没有完成人工实时观看或真人试听终审**。音乐是否适合、合盖声是否足够克制、整体节奏是否符合尚尚的偏好，仍需要实际播放后判断。

后续改音乐时，优先改包络、段落与动作声的关系；目前没有“必须重新生成”的证据。
